# GRAB Research Benchmark Website

Static website for the GRAB: Grasping Real-World Attribute Benchmark research project.

## Publish

Upload `index.html`, the `css` folder, and the `js` folder to the root of your GitHub Pages repository. Under Settings > Pages, choose Deploy from a branch, `main`, and `/(root)`.

## Edit

- Main text and links: `index.html`
- Appearance: `css/style.css`
- Interactions: `js/script.js`

Do not publish confidential or unpublished research materials without permission.
