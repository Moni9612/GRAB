01 / PIPELINE

Real-World Robotic Grasping Pipeline

Repository ↗

GRAB is a comprehensive benchmark designed to evaluate grasping-in-clutter performance in real-world food waste contaminant sorting. This repository provides setup instructions for two grasping benchmark pipelines: a parallel grasping pipeline for rigid and adaptive force-controlled parallel grippers, and a suction-based grasping pipeline.

02 / DEFORMABILITY

Object Deformability Score (QO) Computation Methodology ↗

This uses a technique to calculate the object deformation by comparing the before and after compression point clouds of deformable objects.
