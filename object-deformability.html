Object Deformability Score Calculation

The Object Deformability Score (QO) is a pre-grasp attribute used in the GRAB benchmark to characterize object deformation and its influence on robotic graspability.

1. Object Deformability as a Graspability Attribute

In the GRAB benchmark, the Object Deformability Score (QO) characterizes the intrinsic deformation behaviour of individual objects and is determined prior to grasp trial execution.

The benchmark incorporates 21 distinct objects, comprising three representative items from each of seven inorganic contaminant categories. All objects weigh less than 100 g and fit within a bounding volume of 20 × 10 × 10 cm³, ensuring compatibility with the gripper payload, opening width, and suction constraints.

Unlike conventional object datasets primarily consisting of rigid objects, the GRAB dataset incorporates both rigid and deformable objects, representing a broad range of geometric and deformation characteristics.

Since object weight and dimensions were constrained to satisfy the grippers' operational requirements, deformability was selected as the primary object-related property for evaluating graspability.

Accordingly, object deformation is parameterized as the Object Deformability Score (QO), representing the object-related pre-grasp condition within the GRAB benchmark.

2. Experimental Setup for Deformation Measurement

A customized experimental platform was developed to acquire 3D representations of objects before and during compression, enabling quantitative evaluation of object deformation.

The experimental setup consists of a UR10 robotic manipulator equipped with an OnRobot RG2 parallel gripper and customized compression pads. An Intel RealSense D415 RGB-D camera, integrated with RecFusion 3D reconstruction software, was used to capture object geometry before compression and under an applied compression force of 40 N.

To account for directional deformation characteristics, compression was performed independently along the x and y axes.

2.1. 3D Reconstruction and Point-Cloud Acquisition

RecFusion was used to reconstruct the 3D geometry of each object from RGB-D measurements. The reconstruction process involves projecting depth measurements into 3D space using camera intrinsic parameters, followed by frame-to-frame registration and volumetric Truncated Signed Distance Function (TSDF) fusion to generate dense 3D representations.

The reconstructed geometries were exported as 3D mesh files and subsequently processed to obtain point-cloud representations. As part of the data preparation procedure, the exported ASCII-formatted files were converted into binary format for subsequent point-cloud processing.

For each compression direction, two point clouds were obtained: an initial point cloud representing the undeformed object and a second point cloud representing the object under compression.

2.2. Point-Cloud Preprocessing and Alignment

Before deformation measurement, the reconstructed point clouds were preprocessed to isolate the target object from the surrounding environment. Spatial cropping and colour-based thresholding were performed using RecFusion and MeshLab to remove the background, gripper components, and other unwanted points.

To ensure accurate geometric comparison, the undeformed and compressed point clouds were aligned using a two-stage registration procedure.

Step 1 — Coarse Alignment Using MeshLab

The principal axes of the two point clouds were aligned using MeshLab to establish an initial geometric correspondence. This step reduces differences in object orientation and positioning between the undeformed and compressed states.

Step 2 — Fine Alignment Using ICP

Following coarse alignment, the Iterative Closest Point (ICP) algorithm was applied to refine the registration. ICP iteratively minimizes the residual distances between corresponding points in the two point clouds, improving their geometric alignment.

The resulting aligned point clouds were subsequently used to calculate the Density-Aware Chamfer Distance (DCD), providing a quantitative measure of object deformation.
