Object Deformability Score Calculation

This page documents the experimental and computational methodology used to calculate the Object Deformability Score (QO) for the 21 objects included in the GRAB benchmark. The methodology integrates controlled object compression, 3D reconstruction, point-cloud preprocessing, geometric registration, and Density-Aware Chamfer Distance (DCD) to quantify deformation. The complete procedure encompasses the acquisition of undeformed and compressed object geometries, preparation and alignment of the corresponding point clouds, and calculation of a quantitative deformability score. Experimental illustrations and processing demonstrations accompany the methodological descriptions.

Methodology Overview

The methodology begins with controlled compression and proceeds through six sequential processing stages, from object reconstruction to the calculation of the final Object Deformability Score.

Controlled Compression

Object Deformability as a Graspability Attribute

In the GRAB benchmark, the Object Deformability Score (QO) represents an object-related pre-grasp attribute that characterises deformation under an applied force. The dataset comprises 21 objects across seven inorganic contaminant categories, with three representative objects per category. All objects weigh less than 100 g and fit within a bounding volume of 20 × 10 × 10 cm³, satisfying the operational constraints of the evaluated grippers. The dataset encompasses objects with diverse geometric and deformation characteristics. As object mass and dimensions were constrained, deformability was selected as the principal object-related property for graspability evaluation. The property is quantified by comparing 3D representations acquired before and during controlled compression, using DCD as the geometric discrepancy measure.

Experimental Setup for Deformation Measurement

A customised experimental platform was developed to measure changes in object geometry under controlled compression. The platform comprises a UR10 robotic manipulator equipped with an OnRobot RG2 parallel gripper and customised compression pads. An Intel RealSense D415 RGB-D camera and RecFusion 3D reconstruction software are employed to acquire the object geometry. A compression force of 40 N is applied independently along the x and y axes. Measurements along both directions account for directional variations in object deformation and provide a consistent basis for comparative evaluation.

Controlled Compression Procedure

For each object, the undeformed geometry is initially acquired before applying the compression force. The object is then compressed using the robotic gripper, and its geometry is reconstructed under the applied load. This procedure is conducted independently along the x and y directions. Each directional experiment produces a pair of 3D representations corresponding to the undeformed and compressed states. These paired representations constitute the input data for subsequent geometric analysis.

Object Reconstruction

The three-dimensional geometries of the objects were reconstructed using RecFusion software and an Intel RealSense D415 RGB-D camera. For each object, separate reconstructions were acquired before and during compression. The reconstruction process integrates successive depth observations to generate a three-dimensional representation of the object's surface.

This procedure was performed independently for compression along the x and y directions, producing the corresponding undeformed and compressed object geometries. These reconstructions provide the geometric information required for subsequent mesh processing and deformability analysis.

Mesh Export

Following reconstruction, the three-dimensional object geometries were exported from RecFusion as mesh files for subsequent processing. Separate mesh representations were retained for the undeformed and compressed states, allowing the geometric changes induced by compression to be evaluated independently.

These exported meshes provided the input for subsequent background removal, colour filtering, and point-cloud registration.

Background Removal

The reconstructed object geometries may contain unwanted background surfaces, gripper components, and other environmental features captured during the scanning process. To minimise the influence of these non-object regions on subsequent geometric measurements, a two-stage background removal procedure was employed using RecFusion, MeshLab, and a custom Python implementation.

Initially, background removal was performed using RecFusion to eliminate unwanted environmental surfaces while retaining the reconstructed object geometry. This initial processing stage reduced the presence of unnecessary background regions within the exported meshes.

Following the initial background removal, additional filtering was performed using MeshLab to visually inspect the reconstructed geometries and remove residual unwanted points based on their colour attributes. This procedure was further supported by a custom Python script, color_filter.py, which enables colour-based filtering to isolate the target object from remaining background regions and gripper components.

The combined background removal and colour filtering procedure was applied to both the undeformed and compressed object representations. This processing stage ensured that the resulting geometries primarily represented the target object, minimising the influence of unrelated surfaces on subsequent point-cloud registration and DCD calculations.

Following background removal and colour filtering, the processed object geometry files for all 21 objects can be found in the object_meshes directory of the associated GitHub repository.

ASCII-to-Binary Conversion

Following background removal, the processed object geometry files were converted from ASCII to binary format to prepare them for subsequent point-cloud processing and registration. This conversion was performed using the custom Python script binary_ascii.py. The conversion changes the file encoding while preserving the geometric information required for subsequent analysis. The resulting binary-format files were used for point-cloud alignment and geometric comparison.

Point-Cloud Alignment

Following preprocessing and file conversion, the undeformed and compressed object point clouds were aligned within a common coordinate frame. This registration procedure is essential because differences in the position and orientation of the reconstructed objects could otherwise influence the calculated geometric discrepancy. A two-stage registration procedure was employed, comprising coarse alignment using MeshLab and fine alignment using the Iterative Closest Point (ICP) algorithm.

Coarse Alignment Using MeshLab

Initial alignment was performed using MeshLab to approximately align the undeformed and compressed point clouds. This procedure reduced differences in translation and orientation between the two representations, providing an initial alignment for subsequent ICP registration.

Fine Alignment Using ICP

Following coarse alignment, the Iterative Closest Point (ICP) algorithm was employed to refine the registration. ICP iteratively identifies corresponding points and estimates a rigid transformation that reduces the geometric discrepancy between the two point clouds. The registration was implemented using the custom Python script icp_alignment.py. This procedure reduces differences associated with object position and orientation while retaining geometric variations caused by compression.

The aligned point clouds represent the undeformed and compressed geometries within a common coordinate frame. These registered datasets were subsequently used to calculate the geometric discrepancy using Density-Aware Chamfer Distance.

Object Deformability Score Calculation

Density-Aware Chamfer Distance (DCD) was employed to calculate the Object Deformability Score (QO) by quantifying the geometric discrepancy between the undeformed and compressed object geometries. The metric incorporates nearest-neighbour distances and density-aware normalisation to account for variations in point sampling. Let \(S_1\) denote the point cloud representing the undeformed object and \(S_2\) denote the corresponding point cloud under compression. The DCD between these point clouds is formulated as follows:

\[ \begin{aligned} d_{\mathrm{DCD}}(S_1,S_2) = \frac{1}{2}\Bigg( &\frac{1}{|S_1|} \sum_{x\in S_1} \left( 1-\frac{1}{\hat{n}_y} e^{-\alpha\|x-\hat{y}\|_2} \right) \\[10pt] +\;&\frac{1}{|S_2|} \sum_{y\in S_2} \left( 1-\frac{1}{\hat{n}_x} e^{-\alpha\|y-\hat{x}\|_2} \right) \Bigg) \end{aligned} \]
(6)

Notation

\(S_1\): Point cloud acquired before compression.

\(S_2\): Point cloud acquired during compression.

\(\hat{y}\) and \(\hat{x}\): Nearest-neighbour points identified in the opposite point cloud.

\(\|x-\hat{y}\|_2\): Euclidean distance between a point and its nearest neighbour.

\(\hat{n}_y\) and \(\hat{n}_x\): Density-normalisation factors associated with the corresponding nearest-neighbour points.

\(\alpha\): Parameter controlling the sensitivity of the exponential distance term to geometric discrepancies.

The DCD formulation evaluates geometric discrepancies bidirectionally. For each point in \(S_1\), the nearest point in \(S_2\) is identified, and the corresponding distance and density contributions are calculated. The same operation is performed from \(S_2\) to \(S_1\), and the two contributions are averaged. The exponential distance term incorporates the magnitude of geometric differences, while the density-aware factors account for variations in local point distribution. Smaller geometric discrepancies generally yield lower DCD values, whereas larger discrepancies yield higher values. Under the standardised compression conditions, DCD therefore provides a quantitative indicator of relative object deformation.

The DCD calculation was performed independently for compression along the x and y directions. The resulting directional measurements quantify the geometric changes induced by compression along each axis. These measurements were subsequently combined to calculate the final Object Deformability Score.

Calculation of the Final Object Deformability Score

Object deformation may vary with the direction of the applied force. Accordingly, DCD is calculated independently for the x-axis and y-axis compression experiments. Each directional measurement compares the registered undeformed and compressed point clouds. The final Object Deformability Score (QO) is obtained by averaging the two directional DCD values:

\[ Q_O = \frac{ d_{\mathrm{DCD}}^{(x)} + d_{\mathrm{DCD}}^{(y)} }{2} \]

Here, \(d_{\mathrm{DCD}}^{(x)}\) and \(d_{\mathrm{DCD}}^{(y)}\) denote the DCD values obtained from compression along the x and y axes, respectively. Their arithmetic mean represents the object-level deformability score. The same measurement and processing procedure is applied to all 21 objects, yielding one deformability score per object. These scores enable comparative analysis across individual objects and contaminant categories.

Object Deformability Score Results

The DCD-based methodology was applied to 21 objects across seven inorganic contaminant categories. The resulting object-level scores characterise differences in geometric deformation under the standardised compression conditions. The results indicate substantial variation across the investigated categories. Mesh bags and plastic bags exhibit the highest average deformability scores, whereas tin cans exhibit the lowest category-average score.
